# RECPEE - versión multipágina

Esta versión divide el sitio en páginas HTML independientes:

- index.html
- quienes-somos.html
- mision-vision.html
- directiva.html
- actividades.html
- enlaces.html
- contacto.html

## Importante

Mantén en el repositorio actual las carpetas `images/` y el archivo `favicon.ico`.
Sustituye `index.html`, `css/styles.css` y `js/script.js`, y agrega los nuevos archivos HTML en la raíz.

En GitHub Pages usa:
- Branch: main
- Folder: /(root)
